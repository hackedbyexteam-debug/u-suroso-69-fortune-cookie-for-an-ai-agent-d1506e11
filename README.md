Fortune Cookie for an AI Agent: one funny fortune cookie line for an AI agent — the next user pastes an error message, a screenshot of the error message, and then asks what the error is. The program writes the line to `/output/entry.txt` — 110 characters in total (limit 140).

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt`.
